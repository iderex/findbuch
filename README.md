# findbuch

All known general integrable cases of rigid body dynamics form a few small tables scattered across Leimanis, Yehia and Borisov/Mamaev plus dozens of individual papers from 1890 onwards in German, Russian and Ukrainian, some in journals that no longer exist. Nowhere is this an executable data structure. Each row carries the Hamiltonian, the additional integral, the parameter conditions and the domain, and is verified twice: symbolically that the Poisson bracket vanishes, numerically that the integral stays constant along a trajectory.

Planning happens on the issue tracker first. Every decision that shapes
the architecture is written down there with its reasons before the code
that depends on it exists.
